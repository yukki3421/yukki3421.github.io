> 主题：从 π 系列熟悉的 VLA 出发，讲清 World Action Model（WAM）换了什么先验、学什么目标、泛化轴落在哪里，以及为什么当前用视频当作 world state。

# 1. 核心结论

机器人基础模型这两年的主线之一是 **VLA**：用预训练 VLM 吃图像和语言，再接到动作头（π₀ / π₀.₅ 就是这条路上很有代表性的工作）。VLA 把 web 上的语义能力带进了操作，物体识别、指令跟随、开放词汇目标都明显变强。

DreamZero 提出的 **WAM** 不是在 VLA 上多挂一个「预测几帧」的辅助头，而是换了一套建模起点：

```text
VLA:  语义先验（VLM） + 直接学 p(a | o, c)
WAM:  时空先验（视频扩散） + 联合学 p(o_future, a | o_past, c)
```

可以记成：

| | VLA | WAM |
|--|-----|-----|
| 预训练带来的 | what（物体、概念、指令语义） | how（世界如何随时间演化） |
| 策略主要在拟合 | 观测 → 动作 | 未来世界 + 与之对齐的动作 |
| 更擅长的泛化 | 新物体、新语义目标 | 新运动、新环境、异构轨迹 |

论文里的对照例子很清楚：VLA 往往能做「把可乐放到 Taylor Swift 旁边」（认出人 + 接到已有的 pick/move），却很难做「解鞋带」——若机器人数据里从未出现这类运动，仅靠语言层面的「知道要解」不够。原因在于 VLM 先验主要是语义；精细的空间、接触与动力学并没有以同样方式被继承下来。WAM 的回应是：先（联合）预测世界会怎么变，再让电机命令去实现这段视觉未来。

# 2. VLA：强在语义，弱在新技能

## 2.1 路线本身

VLA 把视觉、语言和低层动作放进同一端到端模型，常见做法是：

```text
图像 + 语言
    → 预训练 VLM（或同类多模态骨干）
    → Action Expert / 扩散头（如 flow matching 出 action chunk）
    → 机器人执行
```

相对「大模型只做规划、底层另接 skill 库」的模块系统，VLA 的优点是接口简单、梯度可以贯通。π 系列用 flow matching 生成动作、用 VLM 提供语义条件，已经把这条路推到了很强的实用水平。

## 2.2 先验从哪里来，就决定长板在哪里

VLM 的预训练主要在 **静态图文** 上。它擅长把像素和词语对齐，却较少直接编码「接下来 1～2 秒物理世界如何演化」。于是泛化表现会呈现一种不对称：

- **物体与语义**：相对强。开放词汇、指代、跨物体组合，都能借 web 知识。
- **环境**：往往要靠大量跨场景 teleop，用数据覆盖换分布外稳健性。
- **全新运动 / 动词**：相对弱。若示教分布里没有对应技能，模型很难「发明」出合理的接触与轨迹。

另一种常见补法是扩充 language-conditioned 的运动原语库。但这条路在组合上很难穷尽真实世界的物理交互；相比之下，视频对几乎每一对相邻帧都有监督信号，覆盖方式更稠密。这是后面转向视频世界建模的动机之一。

# 3. WAM：用世界预测来承载动作

## 3.1 定义

**World Action Model** 指一类同时做两件事的策略模型：

```text
1. World modeling：预测未来世界状态
2. Action generation：在该预测下生成 / 对齐动作
```

作者故意不用 Video Action Model 这个名字：视频只是 **当前** 最方便、也最容易从互联网继承先验的 world state；将来同样可以把动作对齐到触觉、力反馈或学习到的 latent 状态上。World 强调的是「未来状态」，Video 只是其中一种实现。

## 3.2 目标函数在写什么

WAM 的中心对象是联合分布：

\[
p(\mathbf{o}_{t:t+H},\,\mathbf{a}_{t:t+H}\mid \mathbf{o}_{0:t},\,\mathbf{c})
\]

可以概念上拆成：

```text
预测未来观测（视觉规划）
        ×
由「当前到未来」反推动作（隐式 IDM）
```

DreamZero 的选择是 **一个端到端模型联合学习**，而不是先训一个视频模型、再单独训一个逆动力学模块。视频预测提供稠密的动态监督；动作头（更准确说是联合去噪里的动作分支）负责把电机命令和这段视觉未来对齐。经验上，失败往往先表现为「视频规划错了」，动作会忠实地跟着错视频走——因此论文有一句很强的归纳：

> 提升机器人能力，很大程度归结为提升视频生成质量。

## 3.3 两条技术谱系

联合预测视频与动作并不始于 DreamZero，大致有两拨：

| 路线 | 做法 | 含义 |
|------|------|------|
| 从零或从 VLA 加 world loss | 有未来预测目标，骨干未必吃过大规模视频生成预训练 | 联合目标在，物理先验弱 |
| 从预训练视频扩散出发 | 在 Wan 等 I2V / 视频 DiT 上长出策略 | 直接继承 web 时空先验 |

DreamZero 属于第二拨，并在数据多样性、自回归长程、实机泛化与跨本体迁移上把 WAM 推得更远。具体模块放到架构篇；实验数字放到数据与泛化篇。

## 3.4 WAM 想同时拿到的三样东西

相对「纯 VLA」和「纯潜空间世界模型」，视频扩散式 WAM 的设计意图是：

```text
端到端梯度（像 VLA 一样直接出动作）
        +
稠密动力学监督（像世界模型一样预测未来）
        +
web 视频里的时空先验（不必全靠机器人数据从零学物理）
```

论文据此强调三条能力：对新任务更友好的 zero-shot、更能消化异构少重复的机器人数据、以及用视频做高效跨本体迁移。这些是主张，验证留给后面实验篇。

# 4. 为什么 world state 选视频

「世界模型」本身是一个大类。附录里和另外两条路线的差别，决定了为什么 DreamZero 走视频，而不是 latent 或 3D point。

## 4.1 三类世界模型

```text
Latent WM（Dreamer、JEPA 等）
  学 p(s'|s, a)
  状态是压缩后的抽象向量
  部署时常常还要规划 / 搜索，才能得到动作序列

3D Point WM（如 PointWorld）
  在三维点 / flow 里建模场景如何被动作推动
  部署时常见 MPC、采样等优化器出动作

视频式 WAM（DreamZero）
  直接学 p(o_future, a | o_past, c)
  未来画面与动作在同一生成过程里对齐
  推理时不再做一层重型 test-time 规划
```

前两类通常是 **前向动力学 + 另找动作**；WAM 把「世界会变成什么样」和「关节怎么动」绑在同一套生成里，这才和实时闭环（DreamZero 叙事中约 7Hz 出 chunk）兼容。

## 4.2 视频作为 world state 的三点理由

**先验已经在预训练里。**  
大规模视频扩散模型在互联网视频上见过大量物体运动、接触与遮挡。机器人阶段主要是把这种先验适配到本机视角，并学会从视觉未来抽出动作，而不是从零拟合物理。

**监督密度高。**  
一条示教轨迹若只对应几个语言标签，语义监督很稀；若对帧序列做预测，几乎每一段时间都有目标。这对学习「如何动」比只拟合稀疏的 episode 级指令更直接。

**未来帧本身就是规划草案。**  
一段预测视频可以读成「手伸向杯子 → 握住 → 放到杯垫」的可视化计划。动作学习变成：生成与之时间对齐的关节（或末端）序列。这比单纯模仿示教曲线多了一层显式的时空结构，也方便用「视频是否合理」来理解成功与失败。

## 4.3 和 π 系列的概念对照

若你已经熟悉 π₀ / π₀.₅，可以用下表做概念换算（不是实现细节对照）：

| 维度 | π 系 VLA | WAM / DreamZero |
|------|----------|-----------------|
| 骨干先验 | 图文 VLM | 视频扩散 DiT |
| 条件 | 当前观测 + 语言（+状态） | 历史观测 + 语言（+状态） |
| 输出 | 动作 chunk | 未来视频 chunk + 动作 chunk |
| 动作学习 | 直接对 \(a\) 做 FM / 行为克隆 | 与预测视觉未来联合 FM（隐式 IDM） |
| 泛化长板 | 语义、物体 | 运动、环境、异构数据 |
| 跨本体经验 | 通常需要带 action 的目标本体数据 | 可进一步用纯视频做经验迁移 |

一句话版：

```text
π₀ ≈ 在语义空间里条件生成动作
DreamZero ≈ 在视频世界里联合生成未来与动作
```

# 5. 本篇要点收束

WAM 相对 VLA，换的是三件绑定在一起的东西：

1. **先验**：从静态多模态语义，转向视频时空动态。  
2. **目标**：从 \(p(a\mid o,c)\)，转向 \(p(o_{\text{fut}},a\mid o_{\text{past}},c)\)。  
3. **泛化叙事**：从「认什么、听懂什么」，转向「没见过的运动与场景如何靠世界预测外推」。

视频被选作 world state，是因为它同时提供可继承的物理先验、稠密的时间监督，以及可对齐动作的规划表征；相对 latent / 3D 世界模型，它还更适合「直接出动作」的实时策略形态。

架构篇会进入 DreamZero 具体怎么做：Wan 骨干与 VAE latent、联合 flow matching、训练时的 teacher forcing，以及推理时 KV cache 与真观测写回。概念上只需先记住——后面所有模块，都是在实现「预测世界，并对齐动作」这一件事。
